Part A — After cloning from GitHub: run the site locally

Prerequisites

  • Install Node.js (LTS) from https://nodejs.org — includes npm.

Steps

  • Open Terminal (PowerShell or Command Prompt).
  • Go to your project folder (adjust path):
cd "C:\Users\YOUR_USER\...\digital-self-gem-448ac62d"
  • Install dependencies (first time or after package.json changes): npm install
  • Start dev server: npm run dev
  • Read the terminal line “Local:” — often http://localhost:8080/ (another port if busy).
  • Open that URL in your browser.

Part C — Projects: tiles, detail pages, blogs, embeds

Navigation map

What you wantFile to edit
Tiles on home (“Recent Projects”) — title, slug, blurbsrc\components\portfolio\ProjectOutcomes.tsx
Full project page — headings, paragraphs, future embedssrc\pages\ProjectDetail.tsx
Routes (already wired)src\App.tsx — route /projects/:slug

Important: The slug string in ProjectOutcomes.tsx must exactly match a key in the projects object in ProjectDetail.tsx. If they differ, you get “Project not found”.

Add a new project (checklist)

  • Add a tile in ProjectOutcomes.tsx with a unique slug (lowercase, hyphens).
  • Add the same slug as a key in ProjectDetail.tsx inside projects.
  • Fill title, tagline, and sections[].

New tab links & embeds

Today, section bodies are plain text strings. For “Open report in new tab”, add JSX links with target="_blank" and rel="noopener noreferrer". For dashboards or YouTube, add an <iframe> (only if the external site allows embedding).

A developer can extend the section type to include optional embedUrl or externalLinks arrays next to your paragraphs.
